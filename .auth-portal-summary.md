## 🎯 Portal Purpose

**Single Responsibility**: Authentication Gateway

The auth portal now has a clear, focused purpose:

1. Allow users to sign up
2. Allow users to sign in
3. Allow users to reset their password
4. Redirect authenticated users to the main application

## 🔄 User Flow

```
┌─────────────────────────────────────────────────────────────┐
│                     Auth Portal Flow                         │
└─────────────────────────────────────────────────────────────┘

New User:
  Visit auth.domain.com
    → Click "Sign Up"
    → Fill registration form
    → Submit
    → Redirect to login page
    → Sign in
    → Redirect to app.domain.com (main app)

Existing User:
  Visit auth.domain.com
    → Fill login form
    → Submit
    → Redirect to app.domain.com (main app)

Forgot Password:
  Visit auth.domain.com
    → Click "Forgot Password"
    → Enter email
    → Receive reset link
    → Click link → auth.domain.com/reset-password?token=...
    → Set new password
    → Redirect to login page
    → Sign in
    → Redirect to app.domain.com (main app)

Already Authenticated:
  Visit auth.domain.com
    → Automatically redirect to app.domain.com (main app)
```

## 📦 Configuration

### Required Environment Variables

```javascript
// API Server
window.VITE_API_URL_SERVER = "https://api.example.com";

// Domains
window.VITE_AUTH_DOMAIN_AUTH = "https://auth.example.com";
window.VITE_AUTH_DOMAIN_APP = "https://app.example.com";

// Redirects
window.VITE_AUTH_REDIRECT_AFTER_LOGIN = "https://app.example.com";
window.VITE_AUTH_REDIRECT_AFTER_LOGOUT = "https://auth.example.com/login";
window.VITE_AUTH_REDIRECT_AFTER_SIGNUP = "https://auth.example.com/login";
```
